# Changelog

## 1.0.0 - 2026-08-29

- Native universal Apple Silicon and Intel macOS package.
- Debian packages validated for ARM64, ARMHF, and AMD64.
- USB and TCP/9100 output, 203 dpi, custom label sizes, gap/mark/continuous
  sensing, density, speed, offsets, tear/peel, mirror, negative, and copies.
- Correct collated and uncollated multi-page copies.
- Independently generated 8×8 Bayer halftone with clean white and full black.
- Malformed raster and numeric-option limits, privacy-safe-by-default diagnostics, explicit LAN sharing, and
  firmware safety policy.
- macOS 27 architecture/deployment audit and documented CUPS 3/PAPPL migration.
- Xcode 27/macOS 27 SDK preview CI gate; final macOS 27 runtime certification
  remains an explicit release test.
- Developer ID Application signing with hardened runtime and a trusted
  timestamp for the embedded macOS filter.
- Developer ID Installer package checks plus notarization, stapling, and
  Gatekeeper validation tooling.
